# Dark Corridor Demo (PSP) — этапы 1–6

Психологический хоррор от первого лица: тёмный коридор, комната с ящиком и запиской,
запертая дверь. Все модели, текстуры и звуки собственные и генерируются в коде.

## Сборка через GitHub
1. Загрузите всю папку (включая `.github`) в репозиторий.
2. Вкладка **Actions** -> Build PSP EBOOT -> артефакт `DarkCorridor-EBOOT`.
3. Положите `EBOOT.PBP` в `ms0:/PSP/GAME/DarkCorridor/` (или откройте в PPSSPP).

Локально: `docker run --rm -v "$PWD":/src -w /src pspdev/pspdev make`

## Управление
| Ввод | Действие |
|---|---|
| Стик Y / X | вперёд-назад / поворот |
| L + стик X | шаг вбок |
| Крестовина вверх/вниз | наклон камеры |
| Крестовина влево/вправо | поворот |
| Квадрат | бег |
| R | фонарик |
| X | взаимодействие |
| START | пауза |
| Треугольник | отладка: FPS, треугольники, свободная память |
| Select | вкл/выкл отсечение граней (см. ниже) |
| Круг | вкл/выкл лок 30 FPS |

## Прохождение
Записка в комнате -> ключ в ящике -> дверь в конце коридора -> проход -> конец демо.

## Оптимизации (этап 6)
- Отсечение по зонам: комната рисуется только когда может быть видна, проход за дверью — только после её открытия.
- Дальняя плоскость 18 м (туман скрывает всё дальше), свет лампы отключается вдали от неё.
- Текстуры RGB565 + swizzle (вдвое меньше трафика памяти).
- Меньше граней у рук, сжатые полосы в HUD-шрифте, таблица синуса в аудио-потоке.
- Лок 30 FPS (круг), CPU/GPU 333/166 МГц.
- Память: ~2,5 МБ статики из 64 МБ.

## Отсечение граней (Select)
Порядок вершин в мире согласован с нормалями, но по умолчанию отсечение выключено:
я не мог проверить, какое направление PSP считает лицевым. Нажмите Select —
если картинка нормальная, оставляйте включённым (меньше полигонов).
Если стены исчезли — нажмите Select ещё раз и поменяйте `GU_CW` на `GU_CCW` в `init_gu()`.

## Если что-то не так
- Поворот/наклон инвертирован: знак у `sceGumRotateY` / `sceGumRotateX` в `render()`.
- Фонарик светит мимо: направление света в `render()` (блок «свет 0»).
- Руки далеко/близко: координаты в `build_viewmodel()`.
